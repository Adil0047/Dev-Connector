## 🧠 About The Project

Dev-Connector is a **full-stack MERN application** where developers can create profiles, share posts, and interact with each other.

This project is part of my journey to becoming a **professional MERN stack developer**, focusing on real-world practices and clean architecture.

---

## ✨ Features

✔️ Developer profiles & dashboard
✔️ Post creation, likes & comments
✔️ Authentication & authorization (JWT)
✔️ REST API with Express
✔️ Responsive React UI
✔️ Global state management (Redux)

---

## 🛠️ Tech Stack

| Frontend | Backend | Database | Auth   |
| -------- | ------- | -------- | ------ |
| React    | Node.js | MongoDB  | JWT    |
| Redux    | Express | Mongoose | bcrypt |

## ⚡ Getting Started

### 📥 Installation

```bash
git clone https://github.com/Adil0047/Dev-Connector.git
cd Dev-Connector
npm install
cd client && npm install
```

### ▶️ Run the App

```bash
npm run dev
```
